### Better-md-skill

**Better-md-skill** is a Markdown documentation engineering skill designed for AI coding agents.

It helps agents create, improve, restructure, audit, and validate Markdown while maintaining content integrity and following established Markdown and documentation standards.

It includes support for:

- GitHub Flavored Markdown
- CommonMark
- markdownlint-inspired validation
- GitHub documentation conventions
- Evidence-based readability principles
- README visual design
- Documentation structure
- Asset and link validation
- Meaning-preserving edits
- AI agent skill workflows

The project follows the **Agent Skills open standard** and can work with SKILL.md-compatible environments including Codex, Claude Code, Gemini CLI, GitHub Copilot, Cursor, OpenCode, and other compatible agents.
