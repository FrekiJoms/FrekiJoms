### Better-md-skill

**Better-md-skill** is a Markdown documentation engineering skill for AI coding agents. It creates, improves, restructures, audits, and validates Markdown while preserving meaning and following established standards.

It focuses on:

- GitHub Flavored Markdown and CommonMark
- markdownlint-inspired validation
- GitHub documentation conventions
- Evidence-based readability principles
- README visual design
- Asset and link validation
- Meaning-preserving edits
- Agent Skills workflows

It follows the **Agent Skills open standard** and is designed for SKILL.md-compatible environments including Codex, Claude Code, Gemini CLI, GitHub Copilot, Cursor, OpenCode, and other compatible agents.
